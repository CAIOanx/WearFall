# Mídias de demonstração do WearFall

Esta pasta reúne os registros visuais reais do protótipo e das interfaces.

## Vídeo de teste
O vídeo fornecido para a documentação foi convertido em `wearfall-demonstracao.gif` (animação para visualizar diretamente no README) e `wearfall-capa.jpg` (capa do vídeo).

**Publicação dos arquivos binários pendente:** estes arquivos precisam ser enviados para esta pasta pelo GitHub, porque o conector disponível nesta etapa só consegue escrever arquivos de texto. Não adicionar referências a GIF ou imagens no README principal antes de os arquivos existirem no repositório.

Depois de enviar, incluir no README principal:

```md
### Demonstração do protótipo

![Teste físico do protótipo WearFall](docs/media/wearfall-demonstracao.gif)
```

O GIF mostra um teste de bancada do protótipo. Não representa validação clínica ou precisão comprovada em quedas reais.

## Capturas das interfaces
Adicionar capturas autênticas, preferencialmente em PNG:
- `dashboard-local.png`: painel conectado ao ESP32 pela rede local
- `site-inicial.png`: página inicial de apresentação
- `site-login.png`: formulário de login da versão web
- `dashboard-online.png`: painel de apresentação da versão web

A dashboard online não recebe dados reais do ESP32. Evitar identificar dados de simulação como leituras reais.
